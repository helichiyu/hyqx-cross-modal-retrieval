# 对齐偏差登记

记录本工程与 HSMTY 平台模板 / 《新项目技术选型与环境复用框架_HSMTY对齐版》的已知差异。
每条差异都写明原因；新增差异必须在此登记，避免下次评审时重复讨论。

## 1. 构建与模块

| 项 | 模板 / 规范 | 本工程 | 原因 |
| --- | --- | --- | --- |
| 根版本 `revision` | `2.0.1` | `2.0.1` | 父 POM `hsmty-module-starter` 用 `${project.version}` 导入 `hsmty-build` BOM，子工程版本必须等于父工程版本，否则解析成 `hsmty-build:1.0.0` 失败 |
| 子模块 `<parent>` | `relativePath` 为空（从仓库解析父 POM） | `relativePath=../pom.xml` | 本工程根 POM 未发布到 Nexus；首次本地构建无需“先注释 `<modules>` 再 install”的迂回步骤。若后续根 POM 发布，可改回空值 |
| Maven 本地仓库 | `settings.xml` 指向 `/ruanjian/maven/repository` | 构建时用 `-Dmaven.repo.local` 覆盖到本机 `~/.m2/repository` | 本机不存在 `/ruanjian/...`；且该旧仓库缓存了错误的 starter POM |
| 测试执行 | 父工程 `skipTests=true` | CLI 用 `-DskipTests=false` 显式开启 | 测试被静默跳过会误判“BUILD SUCCESS” |

## 4. 配置

| 项 | 模板 | 本工程 | 原因 |
| --- | --- | --- | --- |
| 数据源 | 示例值 | `sd_data_engineering` @ `192.168.1.102:13306`，密码为模板 `ENC(...)` 原样保留 | 密码需由平台方确认可在目标环境解密；见待提供清单 |
| Redis | 示例值 | 哨兵 db 3，密码 `ENC(...)` 原样保留 | 同上 |
| `hsmty.verify` / `hsmty.redirect` | 平台地址 | `${HSMTY_VERIFY_URL}` / `${HSMTY_REDIRECT_URL}` 环境变量 | UAP 地址按环境注入，不写死 |
| `router.whitelist` | 按需 | 仅文档路径 | 业务接口全部走平台鉴权链，不擅自放行 |
| `cmr.service.url` | 示例 `/api` | `${CMR_SERVICE_URL:http://127.0.0.1:8080/hs-api}` | 与 context-path `/hs-api` 对齐 |
| 文件存储 | — | `cmr.file.store=local/s3`，默认 local | 本地可跑；生产必须切 s3 |
| 算子 Feign 配置 | 平台 `FeignConfig` + 全局 `FeignResultDecoder` | `CmrOperatorFeignClient` 使用专用 `CmrOperatorFeignConfig`（标准 Spring 编解码器） | 算子返回自有信封 `{code:0,msg,data}`，平台的 `FeignResultDecoder` 只认 `ApiResult{code:"0000"}`，会把 200 响应当成解析失败。专用配置类刻意不加 `@Configuration`，避免被组件扫描成全局默认配置 |
| 测试配置 | — | `start/src/test/resources/application-test.yml` 用 H2 + 空 Redis 密码 + 白名单 `/**` | 模板 `ENC(...)` 在测试环境无法解密；H2 避免依赖外部库 |
| Redis 哨兵 | 主配置固定哨兵 | 哨兵段改为 `on-profile: "!local"`，`local` profile 连单机 Redis | 本机联调没有哨兵；生产/测试仍走哨兵，不受影响 |
| 本地鉴权 | UAP 会话 + 平台安全链 | `local` profile 额外注册 `LocalDevSecurityConfiguration`，在平台安全链之后注入 `local-dev` 身份 | 本机没有 UAP 门户与会话，需要绕过方法级鉴权才能联调；该配置仅在 `local` profile 加载，且放行只在本机使用 |

## 5. 平台接口形态（已核对，非偏差）

- 统一返回 `ApiResult{code,message,data,param}`，成功码 `0000`；分页 `PageResult{current,limit,totalPage,total,rows}`；`03-API契约.md` 已于 2026-11-10 按此口径回改（D-009）。
- 错误码带 `C` 前缀：参数校验 `C100`、权限不足 `C108`（HTTP 401）、文件不存在 `C1003`、上传失败 `C1006`。
- 逻辑删除：`del_flag` 正常 `F`、删除 `T`，只做逻辑删除。
- 前端 `src/core/http.ts` 已按上述结构对齐，`SUCCESS_CODE='0000'`。
