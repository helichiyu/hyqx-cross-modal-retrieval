## 验收标准

- 9 页原型功能全部可用，状态机流转与数据流文档一致（不允许的迁移一律拒绝）
- 建库链端到端：上传数据集 → 可检索，卡住两分支（评定挂起裁决、召回率不足确认）可演练
- 每次检索必有任务记录与检索历史（SRH），结果集可回看、可标采用/废弃
- 策略发布后下一次检索即生效；评测可对比生效/草稿策略
- 6300 端口从浏览器网络不可达；后端所有接口过鉴权
- Liquibase 重复执行幂等；compose 一条命令起全栈

## 风险与备选

- **hsmty 模板拿不到/私服不通**：降级为裸 Spring Boot 3 + MyBatis-Flex 单模块，表结构与 API 契约不变（F2 设计已隔离此风险）
- **上游平台契约迟迟不到（G2）**：首版上传制交付，拉取适配器留接口位；真实 schema 到后只改 401/403 字段映射（算子侧已预留）
- **数据规模超 50 万**：405 切 IVFPQ/HNSW（config 已预留演进路径），后端无需改动
- **单机资源不足**：算子容器独立成机，后端经 HTTP 调用，共享卷改 NFS/对象存储（决策 2 的变体，接口不变）
