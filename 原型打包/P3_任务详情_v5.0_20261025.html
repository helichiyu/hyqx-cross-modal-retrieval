演示与编号【研发】

本页为页内模拟，不请求真实引擎；任务、结果条数与材料均为示例数据，仅用于原型演示。编号按《平台相关ID生成规范-1026》32.1：任务 TASK / 结果集 RST / 材料 MTL，等宽可复制。

核心任务信息
职责
展示单个任务的任务信息，提供返回任务列表入口。
入口/前置
从 P6 任务列表或 P2「查看任务上下文」进入（携 ?task=）。
输入
  • 任务记录：query、模态对、业务场景、策略版本、状态、发起时间；任务编号用于跳转。
处理规则
6 项只读展示；按 URL 的 ?task= 载入对应任务，结果区与材料区同步呈现。
输出
  • 任务信息 6 项 + 状态徽章
异常与边界
无提交、无异步；?task= 不在演示任务内时回落到默认成功任务。
状态
成功 / 失败。
上下游依赖
上游=P6 任务列表、P2 任务上下文；下游=结果区。
检查点
6 项内容正确；?task= 正确载入；成功/失败结果与材料同步。
核心结果
职责
按任务状态展示结果条数与结果入口，或展示失败原因与处置入口。
入口/前置
任务信息卡下方常驻。
输入
  • 任务状态、结果条数（成功）、失败原因（失败）
处理规则
成功 → 展示结果条数 +「查看结果」，跳 P2 并携 ?task=；失败 → 展示一句话失败原因 +「查看失败任务」，跳 P6 失败任务区（携 ?task=&tab=fail）。
输出
  • 结果条数 / 失败原因 + 跳转入口
异常与边界
失败任务只展示失败原因与「查看失败任务」入口。
状态
成功 / 失败。
上下游依赖
下游=P2 结果页、P6 失败任务区。
检查点
成功跳转携 ?task=；失败跳转携 ?task=&tab=fail；按钮文案为「查看结果」「查看失败任务」。
核心材料（只读）
职责
列出本次运行产生的材料，只读展示。
入口/前置
结果区下方常驻。
输入
  • 材料名称、说明、生成时间
处理规则
固定 4 类材料=查询快照 / 策略快照 / 结果清单 / 执行日志；按运行顺序只读排列；失败运行未生成的结果清单以「—」标注。
输出
  • 材料只读列表（名称 / 说明 / 时间）
异常与边界
无写操作；材料缺失时只保留说明。
状态
成功=4 类齐全；失败=结果清单未生成。
上下游依赖
上游=本次运行；下游=无（只读）。
检查点
4 类材料齐全且为只读；名称 / 说明 / 时间正确。
