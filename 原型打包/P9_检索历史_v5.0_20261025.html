总览页面定位 / 闭环 / 模块清单 / 编号与演示性质

本页定位【设计】

「我的查询历史」：七列历史记录列表（置顶，query / 时间 / 模态对 / 结果数 / 状态 / 任务ID / 操作），行内可查看结果、再次执行。

平台全景闭环【研发】

P1 发起检索 → 本页沉淀历史 → 查看结果 P2 / 查看任务 P3 / 再次执行回填 P1。

三级模块清单【设计】

轻模板页（0 主挂）；联动展示：再次执行→P1、查看结果→P2、查看任务→P3。

编号规范与演示性质【研发】

业务编号按《平台相关ID生成规范-1026》32.1：任务 TASK（等宽可复制）。
本页为页内模拟，不请求真实引擎；历史条目/结果为示例数据，不构成交付承诺。

F1历史列表含演示限制，正式实现需另定
职责
七列展示我的历史检索记录（时间/Query/模态对/结果数/状态/任务ID/操作），状态徽标区分成功/失败；操作列=查看结果 / 再次执行。
入口/前置
页面常驻；历史记录来自 P1 发起的检索（仅本人）。
输入
  • 历史条目（任务号 TASK、query、模态对、结果数、状态）
处理规则
列表只读（历史记录不编辑）；行内动作：查看结果跳 P2?task=、再次执行携 ?q= 回 P1。
输出
  • 七列历史列表 + 成功/失败徽标 + 行内两动作（查看结果 / 再次执行）
异常与边界
  • 失败行「查看结果」置灰（失败无结果集）
  • 仅展示本人历史（他人在线任务在 P6）
状态
列表态 / 空态 / 错误态。
上下游依赖
上游=P1；下游=P2（查看结果）/ P3（任务ID）/ P1（再次执行）。
验收点
七列渲染正确；成功/失败徽标正确；失败行查看结果置灰；两动作携参正确。
F2筛选
职责
按关键词、模态对、状态筛选历史列表。
入口/前置
筛选条常驻列表上方。
输入
  • 关键词（query 模糊匹配）、模态对（全部/文搜图/文搜视频）、状态（全部/成功/失败）
处理规则
三条件叠加过滤（AND），实时联动渲染；清空筛选恢复全部。
输出
  • 过滤后的历史列表 + 计数「共 N 条」
异常与边界
  • 过滤后无结果触发空态
  • 处于错误态时任一筛选输入自动回到列表态
状态
默认全部条件为空。
上下游依赖
本页 F1 列表。
验收点
三条件叠加正确；清空恢复默认；空态/错误态切换正确。
F3再次执行
职责
将历史 query 回填至 P1 检索台（快速复用）。
入口/前置
每条历史行的「再次执行」链接。
输入
  • 目标 query（行内）
处理规则
跳 P1 携 ?q= 参数（URL 编码）；P1 侧读参回填关键词。
输出
  • 跳转 P1?q=…（回填关键词）
异常与边界
无（纯跳转，不校验权限）。
状态
静态链接。
上下游依赖
下游=P1（携 ?q=）。
验收点
跳转 P1 且 ?q= 参数正确（URL 编码）。
F4查看结果 / 查看任务
职责
由历史行进入该次检索的结果页（查看结果）或单任务档案（任务ID）。
入口/前置
行内「查看结果」（成功行可点）与「任务ID」链接。
输入
  • 任务号 TASK（行内，等宽可复制）
处理规则
查看结果携 ?task= 跳 P2；任务ID 携 ?task= 跳 P3；失败行查看结果为置灰文本。
输出
  • 跳转 P2?task= / P3?task=
异常与边界
  • 失败任务无结果集，仅可跳任务详情查看失败态
状态
成功可跳结果 / 失败仅可跳任务。
上下游依赖
下游=P2（结果）/ P3（任务详情）。
验收点
跳转参数正确（?task= 随 TASK 编号）；失败行置灰正确。
F6空态 / 错误态含演示限制，正式实现需另定
职责
空态（无匹配）与错误态（历史加载失败）切换。
入口/前置
列表为空或服务不可用时触发。
输入
  • 列表结果（空/失败）、系统错误码 HIST-503
处理规则
无匹配→空态引导（换关键词 / 前往 P1）；服务不可用→错误态 + 重新载入 / 回 P1。
输出
  • 空态提示 + 前往 P1 / 错误态提示 + 重新载入按钮
异常与边界
  • 错误码 HIST-503（系统码，保留）；URL 传 fail=1 演示触发错误态
状态
空态 / 错误态（与列表态互斥切换）。
上下游依赖
下游=P1（前往/回检索台）。
验收点
空态/错误态切换正确；重新载入回到列表态。
F7P9 与 P6 的分工
职责
划清两个任务相关页面的视角：本页=我的查询历史（用户视角），P6=系统全部任务（运行视角）。
入口/前置
本页由左栏导航进入，仅列本人发起的检索。
输入
  • 本页：本人历史（query / 时间 / 结果数 / 状态）
  • P6：全部任务（队列 / 引擎健康 / 失败任务 / 配额）
处理规则
本页只管「查过的 query 去哪儿再查/看结果」；任务调度、失败处置、配额与熔断一律回 P6。
输出
  • 本页出口：查看结果→P2、任务ID→P3、再次执行→P1
异常与边界
  • 他人在线任务与系统级指标以 P6 为唯一来源
状态
静态说明。
上下游依赖
P6 任务管理（运行视角）；P3 任务详情（单任务档案）。
验收点
两页职责无重叠。
