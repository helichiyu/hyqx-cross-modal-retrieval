本页定位【设计】

全系统唯一查询入口：输入文本描述或图/视频文件，选择「查询模态 × 目标模态」发起检索；结果进入 P2 确认与导出。

平台全景闭环【研发】

检索台发起检索 → P6 任务管理调度运行 → P2 结果页确认/导出 → P7 结果运营（导出验收/精选/热词反馈）→ 反馈归因到 P5 策略调整（P8 评测验证）→ 策略发布后下次检索生效；P4 库管理持续供给检索库。九页即此闭环的九个切面。

三级模块清单【设计】

本页主挂 2 个三级模块：检索查询意图澄清（A＝F5）、检索相似查询复用（B＝F6）；全局件：多模态输入 G1（F1/F2）、模态矩阵 G2（F3）、场景标签（F4）。完整历史在 P9、热词运营在 P7。

设计出处与演示性质【设计】

依据 L2 设计_13 页面架构地图 / L3 设计_15 模板 / L4 设计_16 基础件生成；模态能力：4×4 全矩阵 16 种模态对全部可检索（4 模态统一共享空间对齐，2026-10-27 确认）。本页检索为页内模拟，不请求真实引擎；示例数据不构成交付承诺。

F1文本检索输入
职责
输入查询文本，作为文本检索（文搜X）的查询语义；与文件同时存在时以文件为主、文本作语义补充。
入口/前置
常驻可用；文本与文件二选一即可，不强制二者都有。
输入
  • 用户手输文本
  • 单行大输入框（Hero 搜索框），最多 512 字
  • 占位文案给出输入提示（一句话描述或拖入文件），示例词由输入联想 / 意图澄清提供。
处理规则
实时字数统计（0/512，硬截断不允许超长）；输入去首尾空格后参与判定；输入≥4 字触发 F6 联想下拉。
输出
  • 作为 Query 参数进入 F7 检索
  • 不足 4 字的短词走 F5 意图澄清。
异常与边界
  • 仅空格等同未输入
  • 达到 512 字后无法继续输入
  • 无文本也无文件时点检索，红字提示「请输入查询描述，或上传图片/视频文件」，3.5 秒自动消失。
状态
默认空；聚焦输入态；错误态=输入框红框+行内红字。
上下游依赖
下游 F5 澄清 / F6 联想 / F7 检索。
验收点
512 字截断生效；计数实时；空输入拦截并提示。
F2文件输入与查询模态自动识别含演示限制，正式实现需另定
职责
上传图/视频/音频文件，系统自动识别查询模态并点亮对应矩阵行。
入口/前置
拖拽区常驻；未上传时点击或拖入；已上传后该区显示文件卡片。
输入
  • 单文件
  • 支持 JPG/JPEG/PNG/MP4/WAV/MP3
  • 页面文案承诺单文件 ≤100MB。
处理规则
按扩展名判定模态：jpg/jpeg/png→图像、mp4→视频、wav/mp3→音频；识别约 0.9 秒加载态；成功后写入 queryMode，矩阵仅保留该查询模态所在行可选（其余行 35% 置淡），非该行已选自动清除；音频额外默认选中「音搜音」。
输出
  • 文件模态=矩阵查询模态（行）
  • 文件名与模态进入 F7 上下文
  • 成功后可点 × 移除并复位。
异常与边界
  • 类型不符→失败卡片+红字「不支持的文件类型…」
  • 识别中重复点检索→「文件识别中，请稍候」
  • 移除文件后矩阵行限制与已选全部复位。
状态
默认态（虚线上传区）/拖拽高亮/识别中（spinner）/成功（文件卡+识别结果）/失败（红!卡+错误文案）。
上下游依赖
识别结果驱动 F3 矩阵行；文件名进入 F7。原始文件在正式系统留源系统，本中心只存检索要素。
验收点
五类合法扩展名识别为正确模态；非法类型被拦截并给明确文案；成功后矩阵仅该行可选、音频自动选音搜音；×移除后完全复位。
F3模态矩阵选择（查询模态 × 目标模态）含演示限制，正式实现需另定
职责
选择「查询模态 × 目标模态」组合，确定本次检索的模态对。
入口/前置
与上传同处模态矩阵卡片内（矩阵在上、上传为辅助条）；4×4 全矩阵 16 种模态对全部可检索（4 模态统一共享空间对齐）；无库权限账号整组锁定。
输入
  • 4×4 矩阵
  • 行=查询模态（文本/图像/音频/视频），列=目标模态（文本/图像/音频/视频）
  • 上传文件后按 F2 自动锁定查询模态行。
处理规则
16 格均显示对勾、可点，点击置 selected（同时只允许一个）；未开通库权限时可选格置 45% 淡并锁定，点击 toast「当前账号未开通库权限」。
输出
  • 选中模态对（如「文搜图」）作为必填入参进入 F7
  • 占位参数条与 P2 均显示该模态对。
异常与边界
  • 未选模态对直接检索→红字「请在模态矩阵中选择目标模态对」
  • 切换文件致查询模态行变化时，非该行已选自动清除
  • 无权限账号不可选。
状态
可选/选中（蓝底）/置淡（文件锁定其他行）/锁定（无权限）。
上下游依赖
能力清单：4×4 全矩阵 16 种模态对全部可检索（4 模态统一共享空间对齐，2026-10-27 确认）；入参供 F7、P2。
验收点
可选格恰好 16 个（4×4 全亮）；单选互斥；文件上传后非查询行置淡且越行已选被清除；guest 点击被拦截提示。
F4业务场景选择（P5 反推）含演示限制，正式实现需另定
职责
选择业务场景，决定本次检索由哪条策略参数集处理；场景是路由标签，不是策略。
入口/前置
常驻下拉，默认「通用」；右侧「场景配置 ↗」跳转 P5。
输入
  • 选项不由本页维护：P5 策略绑定场景并发布后该场景才出现在此
  • 选项括号内标注当前生效/验证中的策略。演示固定 4 项：通用（STG261018K7M2PQ）、专业（同默认）、作业（STG261025A3F9KX）、训练数据筛选（切换验证中·样板）；括号展示业务编号（STG+日期+安全码，规范32.1）。
处理规则
选择即写入 state.scene；一场景同一时刻只有一条生效策略，无专属策略走系统默认策略 STG261018K7M2PQ 兜底；F5 场景建议标签可回写本下拉。
输出
  • 场景作为入参进入 F7→P2（pScene）
  • 决定后端走哪条已发布策略。
异常与边界
  • 新增 / 编辑场景入口统一在 P5 场景字典（防止悬空）
  • 解绑的场景不应再出现（演示为静态选项，正式由 P5 动态拉取）。
状态
下拉默认通用；切换即时生效，无加载态。
上下游依赖
上游=P5 策略管理「业务场景字典」（唯一来源）；下游=F7/P2/P5；训练数据筛选为样板场景，不代表已发布承诺。
验收点
4 个选项及括号策略文案与 P5 字典一致；切换后 F7 携参 pScene 正确；澄清浮层场景标签点击后本下拉同步。
F5检索意图澄清（浮层，模块A）含演示限制，正式实现需另定
职责
短词/歧义词检索前给一次改写建议，提升召回质量；每个 query 最多 1 轮。
· F-CR-108 检查跨模态检索查询意图澄清准确性：由检索台澄清浮层的响应结果承载（用户选意图后继续检索）。
入口/前置
点检索后拦截弹出；条件=有 query 且去空格长度<4 且该 query 本轮未澄清过。
输入
  • 原始短词
  • 浮层给 3 条建议候选 + 2 个场景建议标签（训练数据筛选/作业）。
处理规则
三条出口：①点建议候选→替换原词直接检索；②点场景标签→同步 F4 场景并按原词检索；③「仍按原词检索」→原词直检。任一出口都把该 query 标记为已澄清，本轮不再弹；×/Esc 关闭则不标记、不检索。
输出
  • 选定的改写词或原词进入 F7
  • 场景标签回写 F4。
异常与边界
  • ≥4 字不触发
  • 同一 query 已澄清过不再触发
  • 纯文件检索（无文本）不触发
  • Esc 与 × 等价关闭。
状态
遮罩浮层默认隐藏；触发显示；选择后关闭并继续；仅 1 轮。
上下游依赖
前端 F1/F4/F7；正式系统建议候选应由后端按召回置信度生成（当前为演示固定项）。
验收点
短词首次检索必弹且仅 1 轮；三出口行为分别正确；场景标签同步下拉；Esc/×不检索不标记。
F6相似查询复用（输入联想，模块B）含演示限制，正式实现需另定
职责
输入时给历史检索与运营热词，减少重复输入。
入口/前置
输入框聚焦且去空格文本≥4 字时下拉显示；失焦 150ms 后收起（保留点击时间）。
输入
  • 历史=本人近 20 条去重（演示 3 条固定）
  • 热词=运营推送 Top3。
处理规则
输入≥4 字即展示两组（演示按输入即现）；mousedown 点选项（避免 blur 先收起）即回填到输入框、更新字数、收起下拉并聚焦。
输出
  • 回填文本进入 F1，等同手输
  • 热词运营在 P7、完整历史在 P9。
异常与边界
  • <4 字不显示
  • Esc 收起
  • 点击弹层外失焦收起
  • 下拉项点击不被 blur 提前吞掉。
状态
隐藏/显示两态；分组标题「历史检索」「运营热词」。
上下游依赖
上游=P9 检索历史（历史）、P7 结果运营（热词）；下游回填 F1。
验收点
≥4 字出现两组、<4 字消失；点选项正确回填并聚焦；失焦/Esc 正常收起。
F7发起检索并携参跳转结果页
职责
校验必填后组装检索上下文，执行检索并跳 P2 结果页（演示为占位确认）。
入口/前置
「检索」主按钮；另有「清空」复位全部条件。
输入
  • Query（文本或文件语义）、文件（可无）、模态对（必填）、场景（必填，默认通用）。
处理规则
前置校验顺序：识别中拦截→文本与文件均空拦截→未选模态对拦截；通过后短词走 F5，否则按钮转「检索中」禁用态约 1.2 秒；文件存在而无文本时 Query 显示「（以文件语义检索）」。
输出
  • 输出四参 Query/文件/模态对/场景，演示弹占位条展示，正式系统携参跳 P2 并创建检索任务（进 P6 调度）。
异常与边界
  • 三类前置校验各自给明确红字/toast
  • 检索中按钮防重复提交
  • 清空复位：文本、模态对、文件、场景回通用、澄清记录、错误提示、联想。
状态
默认「检索」/加载「 spinner 检索中」禁用/完成弹占位条；错误为行内红字 3.5 秒。
上下游依赖
上游=F1-F6 全部入参；下游=P2 结果页（确认/导出）、P6 任务管理（正式系统建任务）。
验收点
三种缺参分别被拦截且文案准确；通过后四参与界面选择一致；检索中防连点；清空后页面回到初始态。
