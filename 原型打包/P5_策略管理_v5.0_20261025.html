页内说明（正文只留操作，说明收进此处）

· 策略 = 向量 / 融合 / 重排三段参数：向量为白名单模型，融合为四模态权重（合计 100%），重排为两阶段开关。
· 保存并发布时三段参数一起生效；融合合计校验只在弹窗内以行内提示呈现（≠100% 标红）。
· 每个参数区只留参数本身；生效入口＝弹窗底部「保存并发布」或变更评估「发布此草稿」。
· 向量模型下拉只列产线白名单内模型，白名单外向量禁入检索库（假跨模态风险防线）。
· 系统默认策略（兜底）作为系统预置行保留在策略列表：标注「系统预置」，仅管理员可编辑、其他角色只读引用；场景无专属策略时自动回落兜底。
· 分层结构：Tab1 策略配置 = 策略列表常驻（4 条业务演示策略 + 系统默认兜底）＋ 页面级大弹窗编辑（弹窗 ≈900px / 88vw · max-height 86vh · 内部滚动 · 底部操作区钉住，× / 取消 / 遮罩 / Esc 关闭后回到列表、列表不丢；仅 基本信息 + 向量 / 融合 / 重排 参数字段）；Tab2 业务场景字典 = 场景管理（场景列表 / 新建场景 / 查看关联策略，场景与策略的关联仍由策略「适用场景」维护）；Tab3 策略运维 = 先选一条策略（下拉，默认第一条）+ 2 个子 Tab（变更评估 / 版本回滚；变更评估有草稿才出 diff，无草稿显示「当前无待发布变更」），两块都针对这条策略，顶部一句业务价值「改前看影响，改坏能回滚」；新建 / 编辑入口在策略列表，底部「保存草稿」不生效、「保存并发布」下次检索生效。
· 正文只留标题 / 控件 / 状态 / 按钮，研发与逻辑说明全部收进本面板；策略状态收敛为 草稿 / 编辑中 / 生效中 三态；编号 STG 保留、版本只用 v1/v2/v3；系统预置行仅保留行尾小徽标。

策略运维定位（保证改策略不翻车）

· 定位：先选一条策略（下拉，默认第一条），再看两块——①变更评估（前提＝该策略存在草稿 / 待发布版本：有草稿才对比上一版，展示配置 diff；无草稿显示「当前无待发布变更（已生效 vX）」并隐藏 diff）②版本回滚（发布后版本历史 + 一键回滚，回写版本 / 状态 / 配置并出核验回执）；顶部只留一句「改前看影响，改坏能回滚」。
· 变更评估闭环：有草稿时 diff + 影响下方 1 行「发布此草稿 / 放弃草稿」——发布＝草稿转生效版（沿用草稿版本号）＋写版本历史＋清空待发布＋列表回「生效中」＋发布回执；放弃＝二次确认后丢弃草稿、状态回「当前无待发布变更（已生效 vX）」；状态条小字标注「草稿来自：编辑策略 → 保存草稿」。
· 场景绑定：由策略编辑弹窗的「适用场景」字段维护，保存并发布后对该场景下次检索生效。

新建 / 编辑弹窗口径（说明性文字统一收进此处）

· 弹窗正文只保留「业务字段 + 控件 + 按钮 + 状态」，口径以本段为准。
· 底部按钮语义：「保存草稿」＝写入策略表、状态停留「草稿 / 编辑中」，不发布、不影响检索；「保存并发布」＝发布到「适用场景」绑定场景，该场景下次检索即生效；「取消 / × / 遮罩 / Esc」＝关闭回列表，未保存的新建空行丢弃，列表不重绘、不丢。
· 基本信息：策略名称（必填，保存 / 发布前校验「请填写策略名称」）+ 适用场景（发布生效的绑定键，场景字典在 Tab2 维护）+ 版本 / 状态（只读回显，状态三态：草稿 / 编辑中 / 生效中）。
· 向量参数：下拉只列产线白名单内模型（来源对齐产线 R2），白名单外向量禁入检索库——白名单是假跨模态风险防线。
· 融合参数：四模态（文本 / 图像 / 视频 / 音频）权重合计须为 100%；行内「权重合计 100% ✓ / （需调整至 100%）」是校验显示而非说明句，≠100% 时数字标红（.sum-line.over）。
· 重排参数：一个开关即「启用重排」＝粗排召回 topN → 精排模型重排；关＝仅用粗排结果。
· 生效口径：三段参数在底部一次性写入——「保存草稿」只存不生效，「保存并发布」与变更评估「发布此草稿」是两处生效入口。
· 只读与状态：系统预置（兜底）策略仅管理员可编辑，其他角色整窗控件与「保存草稿 / 保存并发布」禁用（仅保留禁用态 tooltip）；弹窗头只挂状态徽标（草稿 / 编辑中 / 生效中）与「系统预置」小标。
· 演示口径：演示值只存在于字段默认值（名称「作业场景检索策略」、权重 50/30/10/10、模型「图文对齐 · CLIP双塔 v3」），正式实现由接口回填。下拉项名里的「（白名单）」是模型枚举名（同时作为 data-model 存储值）。

总览页面定位 / 闭环 / 模块清单 / 编号与演示性质

本页定位【设计】

检索中心的「大脑」：三段式管理检索策略——①向量 ②融合 ③重排，每段只留参数本身（② 融合保留四模态权重滑块），加默认策略兜底；策略经评测（P8）验证后保存并发布，对 P1 下次检索即生效。页面类型＝配置/编辑页（规范2.3），编辑弹窗底部主操作唯一＝保存并发布。

平台全景闭环【研发】

P7 结果运营反馈 / P8 评测建议 → 本页配三段参数（F5–F7）→ F9 保存并发布 → P1 下次检索生效 → P6 调度 → P2 结果 → 回到 P7/P8；P4 新库投产由库管理页自行校验，本页默认策略行直接编辑兜底参数（F8）。

三级模块清单【设计】

A 档×4：向量 / 融合 / 重排 / 默认策略；B 档×2：变更评估·版本回滚（先选一条策略；场景绑定并入策略编辑「适用场景」）。功能点 F1–F3、F5–F12 与之对应（运维两块聚合到 F11，权限归 F12）。

编号规范与演示性质【研发】

策略 ID 按《平台相关ID生成规范-1026》32.1：内部主键雪花 19 位不外暴；业务编号=STG+yyMMdd+6 位安全码（等宽可复制）；语义编码=小写下划线、发布不可改。版本号 v1/v2/v3 保留。
本页 库/任务/策略编号已按 canonical 统一为 KB / TASK / STG；评测、反馈为历史前缀，正式实现按 canonical 归并为 EVL / FBK。
所有校验结果均为页内写死演示，不请求真实引擎，不构成交付承诺。

F11策略运维：变更评估 / 版本回滚含演示限制，正式实现需另定
职责
运维对象＝下拉选中的一条策略（默认第一条）。只保留两块：①变更评估（前提＝该策略存在草稿 / 待发布版本：有草稿才对比上一版，展示配置 diff；无草稿显示「当前无待发布变更（已生效 vX）」并隐藏 diff）②版本回滚（发布后版本历史 + 一键回滚，回写版本 / 状态 / 配置并出核验回执）。有草稿时 diff + 影响下方一行「发布此草稿 / 放弃草稿」：发布即草稿转生效版并出回执，放弃需二次确认后回到无变更。
入口/前置
  • 「策略运维」区先选策略（下拉，默认第一条），再切 2 个子 Tab，默认「变更评估」；变更评估的前置＝该策略有草稿 / 待发布版本，无草稿只显示状态句、不出现 diff；管理员可操作，访客只读
输入
  • 选中策略的待发布草稿 vs 上一版（生效版）的配置 diff（向量 / 融合权重 / 重排 三段差异）+ P7 待处理 FB-0417
  • 版本历史：按选中策略返回各版本（草稿待发布 / v3 / v2 / v1），非当前版本且非草稿提供回滚入口
处理规则
  • 选中策略后 activateTab 切换 2 个子 Tab（变更评估 / 版本回滚）
  • 变更评估先判断前提：有草稿才渲染草稿 vs 上一版的 diff、影响场景、日均任务、关联评测，无草稿只显示「当前无待发布变更（已生效 vX）」并隐藏 diff；评估结果只展示；有草稿时下方一行「发布此草稿 / 放弃草稿」——发布沿用草稿版本写入版本历史并出回执，放弃二次确认后回到无变更；采纳 P7 建议走 F10
  • doRollback：二次确认，回写版本 / 状态 / 配置，适用场景同步回退，未发布草稿随之放弃，生成核验条与回执；回滚后可再次发布恢复
输出
  • 评估结果＝diff / 影响场景 / 日均任务 / 关联评测的只读展示
  • 发布草稿后的发布回执：生效版本 / 配置摘要 / 生效时间；放弃草稿后状态回「当前无待发布变更（已生效 vX）」
  • 回滚后版本表状态回写，适用场景同步到目标版本
异常与边界
  • 无待发布草稿时不出现 diff / 影响区域，避免「没改也评估」；回滚须同步适用场景与配置，不能只改版本号
  • 回滚入口只对非当前版本且非草稿的版本开放
  • 演示为静态数据与 toast，正式由配置中心存储并保留审计台账
状态
  • 有草稿 / 无草稿两种评估态；子 Tab 切换；二次确认弹层；回滚核验条与回执
上下游依赖
  • 上游=P7 反馈；下游=F3 场景字典、P1 场景策略、审计台账
验收点
下拉默认第一条策略、切换后两块同步；仅 2 个子 Tab 可切；有草稿的作业策略显示「待发布变更：v3 → v4（草稿）」与 diff / 影响场景 / 日均任务 / 关联评测，以及「发布此草稿 / 放弃草稿」；专业策略显示「当前无待发布变更（已生效 v2）」；回滚二次确认、回写版本与适用场景、生成回执。
