F1检索上下文条
职责
展示本次检索的查询对象、模态对、任务号，提供「查看任务上下文」「修改检索」两个跳转。
入口/前置
常驻；来自 P1 检索发起（携 query/模态对/场景）。
输入
  • query（上游带入）、模态对、任务号（TASK 业务编号，等宽可复制）
处理规则
仅展示不可编辑；「查看任务上下文」跳 P3（携 ?task=），「修改检索」回 P1（携 ?q= 回填）。
输出
  • 两个跳转：P3?task= / P1?q=
异常与边界
只读展示，无提交无异步，本点不涉及异常。
状态
静态展示。
上下游依赖
上游=P1；下游=P3 / P1。
验收点
query/模态对/任务号正确；两个跳转参数正确。
F3批量操作
职责
对勾选条目批量回源下载。
入口/前置
勾选 ≥1 条时显示批量条。
输入
  • 勾选的条目集合（单次 ≤ 200 条）
处理规则
批量回源下载＝两层权限校验。
输出
  • 已选计数、批量条显隐、toast
异常与边界
  • guest 无下载权限
  • 超 200 条自动截断并提示
状态
隐藏（0 条）/ 显示（≥1 条）。
上下游依赖
下游无跳转（下载在本页完成）。
验收点
计数正确；权限拦截正确。
F4结果筛选
职责
按质量等级区间、相似度阈值、来源过滤结果。
入口/前置
侧栏常驻，可收起。
输入
  • 质量等级区间 D~A（双柄）、相似度阈值 ≥0.50、来源下拉
处理规则
双柄质量区间、相似度阈值滑块、来源下拉；实时联动渲染结果卡片。
输出
  • 过滤后的结果卡片（F6）
异常与边界
  • 过滤后无结果触发空态归因（F7）
状态
默认全部；收起/展开。
上下游依赖
本页内联动 F6；质量等级继承自 P4 接入评定。
验收点
三筛选联动正确；重置恢复默认。
F5展示方案（联动 D4）
职责
按模态分组、排序、对齐热力图开关展示结果。
入口/前置
展示方案条常驻；分组/排序/热力图默认在 P7 配置。
输入
  • 分组 Tab（全部/图像/视频/文本/音频）、排序（相似度降序）、热力图开关
处理规则
分组=按模态过滤；排序=相似度降序；热力图开关默认关，开启显示文/视对齐分并按蓝→红着色。
输出
  • 结果卡片重排 / 对齐分着色（F6）
异常与边界
  • 文本分组 0 条置灰
  • 对齐分默认收起（开关 HTML 与 JS 初始态一致）
状态
默认全部 + 相似度排序 + 热力图关。
上下游依赖
上游=P7 展示方案配置；本页 F6。
验收点
分组/相似度排序/热力图联动正确；开关初态一致。
F6结果列表与条目
职责
展示结果卡片（缩略图/来源/质量等级/相似度/对齐分），支持勾选、单条回源下载、单条反馈。
入口/前置
结果区常驻（结果态）。
输入
  • 结果条目（ITM 编号、来源、模态、相似度、质量等级）
处理规则
卡片勾选→批量条（F3）；单条回源下载=两层权限+来源标注；单条反馈→弹窗（F8）。
输出
  • 卡片列表 + 下载/反馈 toast
异常与边界
  • guest 无下载权限
  • 结果区按 Top50 分页口径（演示为 Top8 预览）
状态
结果态 / 加载态（骨架屏）。
上下游依赖
上游=F4/F5 过滤排序；下游=F3 批量 / F8 反馈。
验收点
样例条目渲染正确；勾选/下载/反馈行为正确。
F7空结果归因处置（主挂）
职责
空结果时给归因三分类 + 三动作。
入口/前置
无结果时触发空态。
输入
  • query、目标库、归因分析结果
处理规则
归因三分类（过滤过严/语义偏离/覆盖缺失）；三动作=放宽过滤（回 P1 ?relax=1）/相似 query（回填 P1）/需求登记（回 P7 ?zero=）。
输出
  • 三张归因卡 + 三个动作
异常与边界
  • 空态只显示归因卡，不显示结果列表
状态
空态。
上下游依赖
下游=P1（放宽/相似）、P7（需求登记）。
验收点
三归因卡文案正确；三动作跳转携参正确。
F8反馈归类入口（联动 P7）
职责
把结果反馈送入 P7 反馈面板；登记归类与分发在 P7 完成（主挂 D4，本页只做入口）。
入口/前置
检索上下文条右侧「结果反馈归类 →」链接（携结果集编号）。
输入
  • 结果集编号 RST（随链接携带）
处理规则
点击跳 P7 反馈面板；反馈表单统一在 P7 维护。
输出
  • 跳转 P7?rs=…
异常与边界
纯跳转，无提交；反馈类型必选等校验在 P7 执行。
状态
静态链接。
上下游依赖
上游=本页结果集；下游=P7 反馈面板。
验收点
链接携结果集编号正确；P7 侧可定位反馈面板。
F9视图状态与系统边界
职责
声明本页可呈现的视图状态（结果/加载/空结果/引擎错误/边界）与产品硬边界。
入口/前置
左下角「原型演示」浮条切换视图，仅用于评审覆盖；正式由接口状态驱动。
输入
  • 视图选择（五态按钮）
  • 登录态与库授权（正式决定可见范围，由 P4 授予）
处理规则
五态互斥显示；边界态列四条硬约束：Top50 分页 / 批量 ≤200 / 回源两层权限 / 无共享空间组合不渲染。
输出
  • 当前视图状态 + 边界说明
异常与边界
  • 错误态含系统错误码 ENG-TIMEOUT-504，可重试
状态
五态切换即时生效。
上下游依赖
上游=P4 库管理（库授权）；视图状态由任务/结果集接口给出。
验收点
五态切换正确；边界态四条齐全；错误态可重试回结果态。
