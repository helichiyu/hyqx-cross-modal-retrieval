# 跨模态检索中心 · 菜单、权限、字典与编号登记

> 号段为占位自选（裁决 7）：菜单 18 位号段 **7066** 起、字典来源号段 **3100**；若团队登记簿另有分配，以登记簿为准并回改本文件与 Liquibase 初始化脚本。

## 一、角色与权限码映射

| 角色 | 用途 | 可访问权限码 |
| --- | --- | --- |
| admin 管理员 | 全部 | 全部权限码 |
| operator 运营 | 运营/评测/策略/检索 | search:*、task:*、eval:*、strategy:*、feedback:*、word:*、file:read |
| user 普通检索用户 | 检索与查看 | search:create/page/adopt、task:page/detail、file:read |

权限码 = API 契约标注的 `cmr:{资源}:{动作}`，动作枚举：create/update/remove/page/detail/adopt/publish/run/confirm/adjudicate。

## 四、业务编号前缀登记（本项目自登记，遵守平台 ID 规范）

| 对象 | 前缀 | 来源 | 示例 |
| --- | --- | --- | --- |
| 任务 | TASK | 平台字典已有 | TASK261103A3F9KX |
| 数据集 | DS | 平台字典已有 | DS261103K7M2PQ |
| 数据源 | SRC | 平台字典已有 | SRC261103A1B2C3 |
| 策略 | STG | 平台字典已有 | STG261103D4E5F6 |
| 检索历史 | SRH | 平台字典已有 | SRH261103G7H8J9 |
| 评估评测 | EVAL | 平台字典已有 | EVAL261103K2M3N4 |
| **结果集** | **RST** | **本项目登记**（算子 408 已按 RST 前缀生成） | RST20261103153000A1B2C3 |
| **反馈单** | **FBK** | **本项目登记** | FBK261103P5Q6R7 |
| **推荐词** | **REC** | **本项目登记** | REC261103S8T9U2 |

规则（平台 ID 规范 32.1）：`前缀+yyMMdd+6 位 CSPRNG`（去 0/O/1/I/L 的 31 字符集）；主键雪花不对外；语义编码小写（算子编号 `401m_ingest_check` 即第三层）；编号 monospace + 一键复制；不复用、碰撞自动重试。
