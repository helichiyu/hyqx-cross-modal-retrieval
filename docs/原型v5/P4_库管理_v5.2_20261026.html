接口对接定义

本平台通过 HTTP 接口从上游数据集平台拉取「原始数据集」，上游只需提供原始文件与元数据，不需要提供向量。

数据集级字段
字段类型必填说明
dataset_idstring必填数据集唯一标识
namestring必填数据集名称
item_countint必填条目数
modal_typesarray可选声明包含哪些模态，仅用于展示
条目级字段
字段类型必填说明
item_idstring必填条目唯一标识
modalsarray必填1~4 个模态，每条自己声明
modals 每项结构
{ type: "image", url: "…jpg" }
{ type: "text", content: "…" } 或 { type: "text", url: "…" }
{ type: "audio", url: "…wav" }
{ type: "video", url: "…mp4" }
接口

GET{base}/datasets/{id}数据集详情
GET{base}/datasets/{id}/items条目列表（item_id / modal_type / id / url），分页
关键约束

  • 同一条目下的多个模态即对齐关系，无需额外字段
  • 缺 modals → 无法确定模态，不可接入

研发需求说明

给研发
一、定位
  • 把上游的数据集平台对接进来，作为检索的数据来源。
  • 不需要被检索的数据集放进黑名单排除掉。
  • 本页只有两块：数据源列表 + 黑名单抽屉；接口对接定义、测试连接、对接数据源都是数据源块内的弹窗。
二、数据源
项说明
名称数据源名称，必填
地址以 http:// 或 https:// 开头，必填
连接状态已连接 / 未连接 / 连接失败
上次同步最近一次同步时间，格式 yyyy-MM-dd HH:mm
测试连接每行都可发起；弹窗先输出 2 行接口检测（接口可达 / 返回数据集列表），再逐字段校验 4 个必填字段（dataset_id / name / item_count / modals）；全部通过才置为已连接并补上次同步时间，缺项则接入失败、状态不变
字段完备4 个必填字段的提供比例；全提供为绿色 4/4，缺项为红色如 3/4，悬浮显示缺失字段
向量化已连接的数据源显示「已完成 / 总数」（如 27,930 / 27,930），全部完成为绿色，未完成橙色并悬浮显示百分比；未连接显示「—」
操作每行「测试连接」；已连接的数据源额外显示「同步」，点击刷新上次同步时间
对接「＋ 对接数据源」在数据源块头右上角，填名称与地址，加入列表末尾，初始为未连接
列表列名称 / 地址 / 状态 / 字段完备 / 向量化 / 上次同步 / 操作，共 7 列

地址属于部署配置；对接记录存 sessionStorage.cm_datasources，刷新保持。

三、黑名单
字段说明
数据集 ID必填，且不与已有记录重复
名称必填
来源名必填，与结果页结果条目的「来源」同名，如 产线作业语料包v2.3；P2 按它做数据源级排除
地址必填，数据集在数据源中的路径，如 /prod/4mod/v2
加入时间提交时自动写入，格式 yyyy-MM-dd HH:mm
  • 入口：数据源块头「黑名单 (N)」，点开为右侧抽屉，N 为黑名单条数；抽屉列表列为 数据集 ID / 名称（下方带来源名）/ 地址 / 加入时间 / 操作（移出）。
  • 添加：「＋ 添加黑名单」填数据集 ID / 名称 / 来源名 / 地址，提交后置顶。
  • 生效：结果页按「来源名」匹配结果条目的来源并排除其条目；可随时移出，刷新后按最新黑名单重算。
  • 存储：写入 sessionStorage.cm_blacklist，数组，元素 {id,name,src,addr,time}，刷新保持。
  • 空态：黑名单为空。
四、接口对接定义

上游只提供原始文件与元数据，不提供向量。下面是拉取原始数据集所需的字段与接口。

项说明
上游提供原始文件与元数据；向量由平台自己抽，上游不需要提供
数据集级3 个必填：dataset_id、name、item_count；1 个可选：modal_types（仅用于展示）
条目级2 个必填：item_id、modals（1~4 个模态，每条自己声明）
modals每项 { type:"image", url } / { type:"text", content 或 url } / { type:"audio", url } / { type:"video", url }
对齐同一条目下的多个模态即天然对齐，不需要额外字段；契约无 align_pairs / vec_model / storage_url，上游也不提供向量
接口GET {base}/datasets 列出数据集；GET {base}/datasets/{id} 数据集详情；GET {base}/datasets/{id}/items 条目列表（分页）
入口数据源块头「接口对接定义」按钮，弹窗只读展示数据集级 / 条目级字段、modals 结构、接口与关键约束
测试连接先检测 2 行接口（接口可达 / 返回数据集列表），再逐项检测 4 个必填字段；全部提供才接入成功，缺任一项（含 modals 只给 type 未给 url）则接入失败、状态不变
  • 每个数据集的模态构成可以不同，由条目级 modals 逐条声明。
  • 同一条目下的多个模态即对齐关系，无需额外字段。
  • 缺 modals → 无法确定模态，不可接入。
五、平台侧处理

接入 → 检测契约 → 拉取原始数据集 → 自动向量化（图文对齐 · CLIP双塔 v3）→ 写入向量库 → 可检索

  • 向量由平台抽取，上游不需要提供向量。
  • 统一向量空间固定为「图文对齐 · CLIP双塔 v3」，不可切换（见 P5 策略管理的向量参数）。
