研发需求说明

给研发
总览页面定位 / 记录口径 / 闭环 / 重放

本页定位【设计】

搜索结果摘要页，由两块组成：任务信息（任务号、状态、当时条件、检索策略与结果数）+ 结果摘要（Top-20）。

记录口径【研发】

搜索结果只存 Top-20 摘要（条目 ID + 名称 + 分数），不存图片本体。用途＝判断匹配度、勾选不匹配条目 → 提交到结果运营做反馈处理。摘要保留 30 天，30 天后过期；只保留任务记录里的条数与赞踩汇总。

页面闭环【研发】

搜索行为 任务列表「详情」进入 → 本页任务信息 / 结果摘要 → 勾选不匹配 → 「标记不匹配」写入反馈单，结果运营 读取并处理。

重放与编号【研发】

?replay=1 或 ?from=replay 时顶部显示重放条：当时 ?was=（缺省取任务记录条数）→ 现在本次重放条数，结果摘要展示本次重放的摘要条目；?task= 载入任务，摘要优先读会话存储 cm_task_summary（键=任务号，值含 q / time / n / pair / stg / thr / items）。有记录时展示真实任务信息与摘要表；无记录时显示「未找到该任务的摘要」空态，不复用其他任务记录；仅 TASK261025A3F9KX / TASK261024K7M2PQ 两个内置演示任务号在无记录时保留演示摘要。任务 TASK / 条目 ITM 等宽可复制；本页为页内模拟，不请求真实引擎。

核心任务信息
职责
展示任务号、状态与当时的检索条件、检索策略、结果数、记录方式。
入口/前置
从 搜索行为 任务列表「详情」进入（携 ?task=）。
输入
  • 任务记录：任务号、搜索词、模态对、检索策略（策略 ID 或名称）、时间、结果数（当时）、状态；记录方式固定为轻量摘要。
处理规则
按 ?task= 载入；优先读 cm_task_summary，有记录用其中的 q / time / n / pair / stg / thr 与 items 渲染（结果数（当时）取 n）；无记录且不是内置演示任务时显示「未找到该任务的摘要」空态。?replay=1 或 ?from=replay 时显示重放条，当时条数取 ?was=（缺省摘要条数），现在条数取本次摘要条数。
输出
  • 任务信息卡内 8 项字段（任务号 / 搜索词 / 模态对 / 检索策略 / 时间 / 结果数（当时）/ 状态 / 记录方式）+（重放时）重放条
异常与边界
优先读 cm_task_summary；无记录且 ?task= 不是内置演示任务号时显示「未找到该任务的摘要」空态（不复用其他任务记录），任务号仍显示 URL 中的真实任务号，封存按真实任务号判定；失败任务同样展示任务信息。
状态
成功 / 失败 / 未找到摘要。
上下游依赖
上游=搜索行为 任务列表与结果页写入的摘要；下游=结果摘要区。
检查点
任务号、状态均在任务信息卡内（不在面包屑行），任务号为等宽字体且可整段复制；检索策略显示摘要里的策略 ID 或名称（取不到显示「—」）；记录方式文案为「轻量摘要（Top-20）· 保留 30 天」；?task= 正确载入；无摘要的未知任务显示空态、不出现演示数据；重放条当时/现在条数正确。
核心结果摘要
职责
展示本次检索的 Top-20 摘要条目，支持勾选不匹配条目并标记，提交后进入结果运营反馈处理。
入口/前置
任务信息卡下方常驻。
输入
  • 摘要条目（结果页写入的 items，最多 20 条）：排名、条目 ID、名称、相似度；本次摘要的实际条数。
处理规则
  • 按相似度降序渲染摘要条目；有摘要时标题为「结果摘要（共 N 条）」，N = items 条数。
  • 勾选实时更新「已选 N 条」，0 条时「标记不匹配」禁用。
  • 点「标记不匹配」→ 勾选条目写入会话存储的反馈单（cm_mismatch_feedbacks），每条含 id / task / q / items[{id,name}] / time / cls:'标记不匹配' / judge:'data' / st:'待处理' / src:'结果摘要'；任务号记入 cm_marked_tasks 并封存本页，toast「已提交 N 条不匹配记录」。
  • 封存后勾选框与按钮全部禁用、按钮变灰；加载时任务号已在 cm_marked_tasks 内则直接封存。
  • 无摘要且不是内置演示任务号时显示空态，不渲染演示摘要。
输出
  • 摘要表（N 行）+ 已选计数 + 反馈单落盘 + 封存态
异常与边界
  • 失败任务未生成结果摘要：只展示失败原因与「查看失败任务」，不显示表格与勾选。
  • 无 cm_task_summary 记录且不是内置演示任务号：显示「未找到该任务的摘要」+「摘要仅保留 30 天，或该任务已过期」，不复用其他任务记录。
  • 名称超长省略并保留 title；勾选为空时不产生标记动作。
状态
有摘要 / 未生成 / 未找到摘要。
上下游依赖
上游=任务记录、结果页写入的 cm_task_summary 与本次重放；下游=结果运营（勾选条目的反馈处理入口）。
检查点
有摘要时按 items 行数渲染（结果页 12 条即 12 行）；演示任务无摘要时保持 20 行；相似度降序；已选计数与按钮可用态一致；提交后复选框全部禁用、按钮变灰并显示「已提交，不可重复标记」，重复标记不再产生记录；结果运营 列表最前出现「query · 标记不匹配 N 条」。
