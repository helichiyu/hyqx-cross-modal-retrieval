F1检索上下文条
职责
展示本次检索的查询对象、模态对、任务号与运行号，并提供返回来源页与回检索台的入口。
入口/前置
常驻；来自 P1 检索发起（携 query / 模态对 / 检索策略 / 任务号）。
输入
  • query（上游带入）、模态对、任务号（TASK 业务编号，等宽可复制）
处理规则
上下文信息只读；最左「← 返回」按 ?back= 指向 P6 或 P8（无 back 时隐藏），右侧「检索台 →」携当前 q 回 P1 回填；重放态隐藏「检索台 →」。
任务号
任务号由 P1 检索台在每次检索时生成，随 URL 的 task 参数传入；本页赞 / 踩与封存按该任务号归属；收藏记录条目 ID 并附带来源任务号，但跨任务保留。缺省才回落演示任务号。本页加载时把本次任务的任务号与 query 写入会话存储 cm_task_meta（键=任务号，值={q,time,n,pair,user}），供结果运营与效果评测把赞 / 踩归集到 query；同时记录操作人与模态对，供搜索行为展示。写入为合并，保留其他任务记录，最多 50 条。另外，结果页把本次结果集的摘要条目（演示 12 条；正式取前 20 条）与任务号一起写入 cm_task_summary，值={q,time,n,pair,user,stg,thr,items[]}（n=摘要条目数，演示 12），items 每项含 id/name/src/sim/mod；最多 30 条，超出按 time 丢最早，供 P3 搜索结果摘要与 P8 效果评测读取。
输出
  • 查询对象、模态对、任务号、运行号的只读展示 + 「← 返回」/「检索台 →」两个入口
异常与边界
只读展示，无提交无异步；?back= 只认 P6/P8，其他值不显示返回入口。
状态
静态展示。
上下游依赖
上游=P1；下游=P1（检索台 → 携 q 回填）、P6/P8（← 返回）。
验收点
query/模态对/任务号正确（任务号取自 URL 的 task 参数，与检索台一致）；「检索台 →」携当前 q 回填，「← 返回」按 ?back= 指向 P6/P8；重放态不显示「检索台 →」。
重放
?replay=1（或 ?from=replay）时在上下文条下方显示重放条：按当时条件重新执行，不读结果快照；「当时」取 ?was=（缺省 130），「现在」取本次重跑的结果集条数（演示固定 127 条）；重放结果在结果页显示「当时 → 现在」对比。
F2结果筛选
职责
按模态分组、相似度阈值、来源过滤结果，并在结果区提示被硬过滤的条数。
入口/前置
侧栏常驻。
输入
  • 相似度阈值（初值取自所选检索策略的 ?thr=，缺省 0.50）
  • 来源（单选）
来源列表
来源列表从本次结果集里去重生成，可滚动选择，单选；最前固定「全部来源」，每项右侧显示该来源的结果条数。本次演示 8 个来源，含「全部来源」共 9 项，列表区固定高度、超出滚动。
处理规则
相似度阈值滑块、来源列表实时联动，重排结果卡片。相似度阈值来自所选检索策略（?thr=），可在本页临时调整；滑块旁显示「≥ 当前阈值」（随阈值变化），重置筛选回落到策略阈值而非固定值；阈值落在滑块默认区间外时自动撑开区间。
数据源黑名单
结果页会排除 P4 数据源库管理 → 黑名单里来源名命中的数据集：读会话存储 cm_blacklist 的 src，与结果条目的来源比对，命中即不渲染；按条目屏蔽走结果运营（cm_blocked_items），两者独立生效，计数在结果区合并为「本次共排除 N 条」（N = 当前筛选条件下数据源黑名单命中数 + 条目屏蔽命中数）。
过滤清单
结果区显示「本次共排除 N 条」+「查看过滤清单」按钮，点按钮可打开只读清单，逐条列出被排除的条目（条目 ID / 名称 / 来源 / 过滤原因），底部汇总总数与按原因计数（数据源黑名单 / 条目屏蔽）。用于核对是否误杀、漏检是否由屏蔽或黑名单造成；清单只读，不改结果集、不改数据、不写存储。N 为 0 时整行提示隐藏，清单只存在内存、每次渲染按当次筛选条件重算。
输出
  • 过滤后的结果卡片（F4）
异常与边界
  • 筛选后为空时结果区显示「该来源下暂无结果」，可重置筛选，不跳整页空态
状态
默认全部来源。
上下游依赖
本页内联动 F4；黑名单数据来自 P4。
验收点
来源列表由结果集去重生成、单选、可滚动（演示 9 项）；重置恢复「全部来源」并回落到策略阈值（?thr=，缺省 0.50）；筛选为空显示指定空态文案；无黑名单且无条目屏蔽时结果区不显示排除提示；有排除时提示可点开过滤清单，清单条目 ID / 名称 / 来源 / 过滤原因与汇总计数正确，关闭后不改结果集。
F3展示方案（分组 / 排序 / 热力图）
职责
按模态分组、排序、对齐热力图开关展示结果。
入口/前置
展示方案条常驻；分组/排序/热力图均为本页临时状态，不写存储、不回写其他页。
输入
  • 分组 Tab（全部/图像/视频/文本/音频）、排序（相似度降序）、热力图开关
处理规则
分组=按模态过滤；排序=相似度降序；热力图开关默认关，开启显示文/视对齐分并按蓝→红着色。
输出
  • 结果卡片重排 / 对齐分着色（F4）
异常与边界
  • 文本分组 0 条置灰
  • 对齐分默认关闭（开关 HTML 与 JS 初始态一致）
状态
默认全部 + 相似度排序 + 热力图关。
上下游依赖
上游=无（本页临时状态）；下游=F4 结果卡片。
验收点
分组/相似度排序/热力图联动正确；开关初态一致。
F4结果列表与条目
职责
展示结果卡片（来源/相似度/对齐分），支持查看单条详情（缩略图/占位大图 + 名称/条目 ID/来源/相似度/模态）、单条赞 / 踩与收藏/取消收藏。
入口/前置
结果区常驻（结果态）。
输入
  • 结果条目（ITM 编号、来源、模态、相似度）
处理规则
点击卡片→打开查看弹窗（只读，不外发数据）；单条赞 / 踩→直接记录（同方向再点取消，点反方向改为反方向），不弹窗、不触发查看；收藏按钮切换本条收藏态，不触发查看。已屏蔽的条目不出现在结果中：渲染前读会话存储 cm_blocked_items（结果运营屏蔽的条目 ID），命中即不渲染；全部被过滤时显示「该来源下暂无结果」页内空态（不跳整页空结果态）。
输出
  • 卡片列表 + 查看弹窗 + 单条赞 / 踩 toast + 收藏态
评价反馈
单条赞 / 踩不弹窗、不填理由；存储按「任务号 + 条目号」写入 cm_item_votes（值 up/down），query 由 cm_task_meta 按任务号关联；供 P7 结果运营 反馈处理与 搜索行为 按任务号汇总赞 / 踩条目数。页面卸载（beforeunload / pagehide）时把当前任务号写入 cm_sealed_tasks，再次进入该任务即封存本次运行的评价，赞 / 踩不可再改。
评价口径
只做单条评价：赞 / 踩二选一，记在数据条目，供结果运营处理；都不点 = 未评价。不记次数、不记分数、不记平均分。单条赞 / 踩只在当次运行有效；页面关闭后封存不可改；再评价需重新执行（新任务号）。任务号由检索台在检索时生成；离开结果页后该任务封存，想再评价需重新检索或重新执行。
异常与边界
  • 结果区按 Top50 分页口径（演示为 Top12 预览）
状态
结果态 / 加载态（骨架屏）/ 筛选为空（「该来源下暂无结果」）。
上下游依赖
上游=F2/F3 过滤排序；下游=无跳转（查看与评价在本页完成）。
验收点
点击卡片可查看条目详情；赞 / 踩可记录、取消、改向，按任务号 + 条目号落会话存储；收藏按钮可切换并同步收藏夹；关闭页面后该任务号封存，重入时赞 / 踩置灰不可点并显示封存提示，重新执行的新任务号可正常评价。
收藏检索精选资产收藏
收藏
把感兴趣的条目标记下来，写 sessionStorage.cm_favorites（键=条目 ID，值={name,src,time,task}），存在本次会话；收藏夹可查看与移除，跨任务保留。
范围
收藏只记录条目 ID 与元数据，不复制文件本身（数据不出域）；收藏夹条数即 favCount，页头入口显示「收藏夹 (N)」。
F5空结果归因与处置
职责
空结果时给归因三分类 + 三动作，并提供原因分析、处置方案登记与处置跟踪三项工具。
入口/前置
结果集为空时展示空态；演示由左下角「空结果」按钮切换。
输入
  • query、当前筛选条件（阈值/来源）、归因分析结果
处理规则
归因三分类（过滤过严/语义偏离/覆盖缺失）；三动作=放宽过滤（回 P1 ?relax=1）/相似 query（回填 P1）/需求登记（回 P7 ?zero=）。处置工具：发起原因分析（勾选过滤条件回放/语义向量距离/覆盖缺口/索引新鲜度，输出主因与置信度）、登记处置方案（处置方式/责任人/期望完成/方案说明）、处置跟踪（待处置→处置中→已闭环，留痕只存内存）。
输出
  • 三张归因卡 + 三个动作 + 处置登记/跟踪留痕
异常与边界
  • 空态只显示归因卡与处置工具，不显示结果列表
状态
空态。
上下游依赖
下游=P1（放宽/相似）、P7（需求登记）。
验收点
三归因卡文案正确；三动作跳转携参正确；原因分析可输出主因与置信度；处置方案可登记并进入跟踪，状态可推进到已闭环。
