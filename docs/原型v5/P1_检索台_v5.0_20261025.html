本页定位【设计】

全系统唯一查询入口：输入文本描述或图/音频/视频文件，选择「查询模态 × 目标模态」发起检索；结果进入 P2 确认与查看。

平台全景闭环【研发】

检索台发起检索 → P6 搜索行为调度运行 → P2 结果页确认/查看 → P7 结果运营（反馈处理）→ 反馈归因到 P5 策略调整（P8 评测验证）→ 策略发布后下次检索生效；P4 数据源库管理持续供给检索库。八页即此闭环的八个切面。

功能清单【设计】

本页主功能：发起检索并携参跳转结果页（F7）、输入联想（F6）、意图澄清（F5）；全局件：多模态输入（F1/F2）、模态矩阵（F3）、检索策略（F4）、权限态（F8）。完整历史在 搜索行为。

检索类型口径【设计】

检索类型用于收窄目标模态：默认「全部」不限定目标模态，按统一向量空间跨模态混排返回，结果按相似度排序；选择具体模态（图像/文本/音频/视频）时，按当前查询模态自动选对应模态对（如文本→图像=「文搜图」），无对应组合时 toast「{查询模态}输入暂不支持检索「{目标模态}」结果」并保持原选择。

设计出处与演示性质【设计】

依据 L2 设计_13 页面架构地图 / L3 设计_15 模板 / L4 设计_16 基础件生成；模态能力：4×4 全矩阵 16 种模态对全部可检索（4 模态统一共享空间对齐，2026-10-27 确认）。本页检索为前端演示：校验通过后携参跳转 P2，不请求真实引擎；示例数据不构成交付承诺。

F1文本检索输入
职责
输入查询文本，作为文本检索（文搜X）的查询语义；与文件同时存在时以文本 q 发起检索，文件只作上下文（演示不入 URL）。
入口/前置
常驻可用；文本与文件二选一即可，不强制二者都有。
输入
  • 用户手输文本
  • 单行大输入框（Hero 搜索框），最多 512 字
  • 占位文案「输入一句话描述，或拖入图片 / 音频 / 视频…」；示例词由输入联想提供。
处理规则
实时字数统计（0/512，硬截断不允许超长）；输入去首尾空格后参与判定；有任务记录时输入非空即触发 F6 按包含匹配联想，无记录时去空格≥2 字展示示例；联想来自 cm_task_meta 的最近搜索与热门检索。
输出
  • 作为 Query 参数进入 F7 检索
异常与边界
  • 仅空格等同未输入
  • 达到 512 字后无法继续输入
  • 无文本也无文件时点检索，红字提示「请输入查询描述，或上传图片 / 视频 / 音频文件」，3.5 秒自动消失。
状态
默认空；聚焦输入态；错误态=输入框红框+行内红字。
上下游依赖
下游 F6 联想 / F7 检索。
验收点
512 字截断生效；计数实时；空输入拦截并提示。
F2文件输入与查询模态自动识别含演示限制，正式实现需另定
职责
上传图/视频/音频文件，系统自动识别查询模态并点亮对应矩阵行。
入口/前置
拖拽区常驻；未上传时点击或拖入；已上传后该区显示文件卡片。Hero 搜索框也接受拖入文件，与拖拽区走同一 handleFile 流程。
输入
  • 单文件
  • 支持 JPG/JPEG/PNG/MP4/WAV/MP3
  • 页面文案承诺单文件 ≤100MB。
处理规则
按扩展名判定模态：jpg/jpeg/png→图像、mp4→视频、wav/mp3→音频；识别约 0.9 秒加载态；成功后写入 queryMode，矩阵仅保留该查询模态所在行可选（其余行置淡约 32%），非该行已选自动清除；音频额外默认选中「音搜音」。
输出
  • 文件模态=矩阵查询模态（行）
  • 文件名与模态留在本页 state，不入 URL
  • 成功后可点 × 移除并复位。
异常与边界
  • 类型不符→失败卡片+红字「不支持的文件类型…」
  • 识别中重复点检索→「文件识别中，请稍候」
  • 移除文件后矩阵行限制与已选全部复位。
状态
默认态（虚线上传区）/拖拽高亮/识别中（spinner）/成功（文件卡+识别结果）/失败（红!卡+错误文案）。
上下游依赖
识别结果驱动 F3 矩阵行；文件名只留在本页 state，不入 URL。原始文件在正式系统留源系统，本中心只存检索要素。
验收点
JPG/JPEG/PNG/MP4/WAV/MP3 识别为正确模态；非法类型被拦截并给明确文案；成功后矩阵仅该行可选、音频自动选音搜音；×移除后完全复位。
F3模态矩阵选择（查询模态 × 目标模态）含演示限制，正式实现需另定
职责
选择「查询模态 × 目标模态」组合，确定本次检索的模态对。
入口/前置
与上传同处模态矩阵卡片内（一屏布局：矩阵在左、上传区在右）；4×4 全矩阵 16 种模态对全部可检索（4 模态统一共享空间对齐）；未开通库权限的账号不做置淡/锁定，点格时直接拦截。
输入
  • 4×4 矩阵
  • 行=查询模态（文本/图像/音频/视频），列=目标模态（文本/图像/音频/视频）
  • 上传文件后按 F2 自动锁定查询模态行。
处理规则
16 格均显示对勾、可点，点击置 selected（同时只允许一个）；guest 角色点击任意格只 toast「当前账号未开通库权限」，不改选中态、不置淡。
输出
  • 选中模态对（如「文搜图」）进入 F7；未选时（检索类型=全部）pair=全部，不阻断检索
  • 页面「当前模态对」与 P2 均显示该模态对。
异常与边界
  • 检索类型≠全部且无对应模态对时→红字「请先选择检索类型（全部 / 图像 / 文本 / 音频 / 视频）」并抖动检索类型组
  • 切换文件致查询模态行变化时，非该行已选自动清除
  • 无权限账号不可选。
状态
可选/选中（蓝底）/置淡约 32%（文件锁定其他行）。
上下游依赖
能力清单：4×4 全矩阵 16 种模态对全部可检索（4 模态统一共享空间对齐，2026-10-27 确认）；入参供 F7、P2。
验收点
可选格恰好 16 个（4×4 全亮）；单选互斥；文件上传后非查询行置淡且跨行已选被清除；guest 点击被拦截提示。
F4检索策略选择（P5 反推）含演示限制，正式实现需另定
职责
选择本次检索所用的检索策略：检索时直接选一条策略，策略决定本次检索的相似度阈值与重排参数。
入口/前置
常驻下拉，默认「系统默认策略（兜底）」；右侧小字显示该策略的参数摘要。
输入
  • 选项来自 P5 已生效策略（读 sessionStorage.cm_strategies，仅取 status=生效中，草稿与已下线过滤掉；读不到存储时用与 P5 同构的兜底常量，本页不回写存储）
  • 下拉只显示策略名、不显示策略号
处理规则
选择即写入 state.stg；右侧小字随选项动态输出「阈值 x.xx · 重排开/关」（如「阈值 0.60 · 重排开」）；未选择或未知策略号回落系统默认策略 STG261018K7M2PQ。
下拉只列 status=生效中 的策略，草稿与已下线都不出现；若一条生效中都没有，回退「系统默认策略（兜底）」并显示回退提示：存在已下线策略时提示「所有策略已下线，已回退系统默认」，否则提示「暂无生效中策略，已回退系统默认」；检索仍可发起。
输出
  • 策略号作为入参进入 F7 → P2（跳转参数 stg + thr）
  • 本次检索使用该策略的阈值与重排参数
异常与边界
  • 未知 / 已下线的策略号按系统默认策略处理
  • 存储里没有生效中策略（下拉为空）→ 兜底下拉只剩「系统默认策略（兜底）」并按是否存在已下线策略显示对应回退提示
状态
下拉默认系统默认策略；切换即时生效，无加载态。
上下游依赖
上游=P5 策略管理（唯一来源）；下游=F7、P2。
验收点
4 个选项与 P5 已生效策略一致；默认选中系统默认策略（兜底）；右侧摘要与 P5 参数一致；跳转带 stg 与 thr 参数。
F5意图澄清（短词检索前的改写建议）
职责
去空格后 <4 字的短 query 在检索前给一次改写建议，帮助用户把过短输入补成可检索的描述；每个 query 只给一轮建议，不打断正常检索主流程。
入口/前置
点「检索」时触发；前置=有 query 且去空格长度 < 4 且本轮未澄清过该 query。
输入
  • 用户输入的短 query（长度去空格后 < 4）
  • 本轮已澄清的 query 记录（会话存储 cm_p1_clarified，仅本页使用）
处理规则
弹出居中浮层（遮罩 + 约 520px 卡片）：标题「意图澄清」，正文「「{q}」较短或存在歧义，你是不是想找：」；候选按输入 query 拼模板生成三条，不写死文案；底部左「仍按原词检索」、右「每个 query 最多澄清 1 轮」。
输出
  • 选候选 → 候选文本作为 query 进入 F7 检索流程（URL 的 q 即候选文本）
  • 仍按原词 → 原 query 进入 F7 检索流程
  • 关闭 → 不检索
异常与边界
  • ≥4 字不触发
  • 同一 query 已澄清不再触发
  • 纯文件检索（无 query）不触发
  • × / Esc 仅关闭，不检索、不标记
状态
隐藏 / 显示两态；显示时遮罩 + 卡片，点击遮罩或 × 或 Esc 均关闭。
上下游依赖
上游=F1 检索输入；下游=F7 发起检索并携参跳 P2。
验收点
输入「发票」点检索弹出浮层且三条候选由 query 拼出（含{q}的扫描件 / {q} 高清扫描 / {q} 内容示意）；点候选后 URL 的 q 为候选文本；同一 query 第二次点检索不再弹；≥4 字与纯文件检索不弹。
F6相似查询复用（输入联想）含演示限制，正式实现需另定
职责
输入时给最近搜索与热门检索，减少重复输入。
入口/前置
输入框聚焦且有任务记录时，输入非空即可能下拉；无任务记录时需去空格文本≥2 字；失焦 150ms 后收起（保留点击时间）。
输入
  • 读会话存储 cm_task_meta（P2 写入，结构 {task: {q, time, n, pair, user}}）；无记录时用 3 条示例
处理规则
输入非空即按包含匹配（q.indexOf(输入) > -1）展示分组（无任务记录时需 ≥2 字）：最近搜索=按 time 倒序去重取前 3；热门检索=按 query 频次降序取前 3（频次 ≥ 2 才显示）；无记录时展示「示例搜索」分组；mousedown 点选项（避免 blur 先收起）即回填到输入框、更新字数、收起下拉并聚焦。
输出
  • 回填文本进入 F1，等同手输
  • 完整历史在 搜索行为。
异常与边界
  • 输入为空不显示
  • <2 字且无任务记录时不显示
  • Esc 收起
  • 点击弹层外失焦收起
  • 下拉项点击不被 blur 提前吞掉。
状态
隐藏/显示两态；分组标题「最近搜索」/「热门检索」/「示例搜索」。
上下游依赖
上游=P2 写入的 cm_task_meta（搜索行为 展示同一份记录）；下游回填 F1。
验收点
有任务记录时输入命中即出现「最近搜索」/「热门检索」分组、无记录时 ≥2 字出现「示例搜索」；热门检索仅在频次 ≥ 2 时出现；点选项正确回填并聚焦；失焦/Esc 正常收起。
F7发起检索并携参跳转结果页
职责
校验必填后组装检索上下文，生成任务号并携参跳 P2 结果页（演示为前端跳转，不请求真实引擎）。
入口/前置
「检索」主按钮；另有「清空」复位全部条件。
输入
  • Query（文本；纯文件检索时为空，URL 不带 q）、文件（可无）、模态对（可选；检索类型=全部时 pair=全部）、检索策略（必选，默认系统默认策略）。
检索流程
输入 → 校验 → 生成任务号 → 跳结果页。校验顺序：文件识别中拦截→文本与文件均空拦截→检索类型≠全部但无对应模态对拦截；通过后先判 F5：短 query（去空格<4 字且本轮未澄清）弹意图澄清，澄清出口再进入 doSearch。doSearch 生成新任务号，按钮转「检索中」禁用态约 1.2 秒后携参跳转；文件存在而无文本时 URL 不带 q 参数。
任务号
每次检索生成一个新任务号（TASK + yyMMdd + 6 位大写字母数字，去掉 I O 0 1），作为本次搜索的唯一标识，随 URL 的 task 参数带到 P2；同一 query 再次检索也是新任务号。赞踩、反馈、评测都挂在这个任务号上。
输出
  • 携参跳 P2：?from=P1&back=P1&task=&q=&pair=&stg=&thr=（q 为空时省略；文件不入 URL）
  • task 为本次新任务号，pair 未选时为「全部」，stg 为策略号，thr 为该策略阈值（两位小数）
异常与边界
  • 三类前置校验各自给明确红字/toast
  • 检索中按钮防重复提交
  • 清空复位：文本、模态对、文件、检索策略回系统默认、错误提示、联想。
状态
默认「检索」/「检索中」禁用约 1.2 秒后跳转 P2，本页无完成态；错误为行内红字 3.5 秒。
上下游依赖
上游=F1-F6 全部入参；下游=P2 结果页（确认/查看）、P6 搜索行为（正式系统建任务）。
验收点
三种缺参分别被拦截且文案准确；通过后 task/q/pair/stg/thr 与界面选择一致，且任务号为本次检索新生成、与 URL 的 task 参数一致；检索中防连点；清空后页面回到初始态。

上下游依赖

验收点
