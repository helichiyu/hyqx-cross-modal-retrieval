页内说明（正文只留操作，说明收进此处）

· 本页只做一件事：管理检索策略的参数——①向量 ②召回与融合（相似度阈值 / 四模态权重）③重排，以及发布、变更评估与版本回滚。
· 检索策略由「检索台」在检索时直接选择（见 P1 的检索策略下拉），没有中转层；本页只负责策略本身的增删改与生效。
· 策略 = 三段参数：向量为白名单模型；召回与融合含相似度阈值（默认 0.60）与四模态权重（合计 100%）；重排为一个开关（开＝在向量召回结果上再加精排，关＝仅用粗排结果）。
· 保存并发布时三段参数一起生效；参数校验只在弹窗内以行内提示呈现（阈值 0~1、权重合计 ≠100% 标红）。
· 生效入口＝编辑弹窗「保存并发布」或运维弹窗「发布此草稿」；「保存草稿」只登记待发布参数、不改策略状态、不影响检索——生效中策略保存草稿后仍是「生效中」并在状态列标「待发布」，检索台照旧可选；只有新建策略保存草稿才落「草稿」（不进检索台下拉）。
· 向量参数固定为产线白名单内的一套统一向量空间（下拉置灰、不可切换），白名单外向量禁入检索库（假跨模态风险防线）。
· 系统默认策略（兜底）作为系统预置行保留在列表，标注「系统预置」；检索台未选策略时按该策略参数执行。
· 页面结构：单一「策略列表」（每页 10 条，带「共 N 条」+ 上一页 / 页码 / 下一页）＋ 编辑 / 运维两个页面级大弹窗（≈900px / 88vw · max-height 86vh · 内部滚动 · 底部操作区钉住，× / 取消 / 遮罩 / Esc 关闭后回到列表、列表不丢）＋ 下线弹窗（选原因 + 影响说明）＋ 一致性检查弹窗（只读）＋ 通用二次确认（放弃草稿 / 版本回滚）。
· 正文只留标题 / 控件 / 状态 / 按钮，研发与逻辑说明全部收进本面板；策略状态取值为 生效中 / 草稿 / 已下线；编号 STG 保留、版本只用 v1/v2/v3。
· 「保存并发布」成功后，列表下方出现「✓ 时间 已保存并发布：名称 版本」提示与「前往检索台 →」入口（直达 P1）。

运维弹窗口径（从策略行「运维」进入）

· 入口：策略列表每行操作列「运维」→ 弹窗，标题为「策略运维 · 策略名」，弹窗只作用于这一条策略。
· 变更评估：选一条对比策略（下拉，默认系统默认策略），展示四项配置 diff（向量参数 / 相似度阈值 / 融合权重 / 重排方案）；待发布草稿是否存在只看 OPS_PENDING（与行状态是否「草稿」无关），有 pending 才在底部出现「发布此草稿 / 放弃草稿」，无 pending 只展示对比。
· 发布此草稿：pending 参数写入该策略＋写版本历史＋清空 pending＋去掉「待发布」标记＋发布回执；生效中策略发布后版本 +1、状态仍「生效中」，新建草稿策略发布后状态转「生效中」、沿用草稿版本号。
· 放弃草稿：二次确认后清空 pending、去掉「待发布」标记，参数与状态都不变；从未发布过的草稿行（status=草稿）整行移除。
· 版本回滚：版本历史 6 列（版本 / 策略名称 / 变更摘要 / 发布时间 / 状态 / 操作）；未发布草稿单独列在顶部且不可回滚，当前版本按钮置灰，其余行「回滚到此」；回滚回写版本 / 状态 / 配置并出核验回执。版本记录保留发布时的策略名称与参数快照；版本历史只保留最近 10 个版本，超出后最早的自动清理，需要长期留档的版本请在外部登记。

召回与融合口径（相似度阈值 / 融合权重）

· 相似度阈值：低于此值的条目不返回。调高更准更少，调低更全更杂；取值 0~1、步长 0.05，默认 0.60。
· 融合权重：只对含多种表征的条目生效（视频的画面 / 音频 / 字幕）；图片与文档为单表征，不参与加权。四模态权重合计须为 100%。
· 结果条数：由相似度阈值决定，结果分页展示。
· 校验：保存草稿 / 保存并发布前校验阈值 0~1，不通过时行内标红并 toast；权重合计 ≠100% 拦截提交，合计数字标红（.sum-line.over）并 toast「融合权重合计需为 100%」。

新建 / 编辑弹窗口径（说明性文字统一收进此处）

· 弹窗正文只保留「业务字段 + 控件 + 按钮 + 状态」，口径以本段为准。
· 底部按钮语义：「保存草稿」＝把参数登记为待发布（OPS_PENDING）并给行加「待发布」标记，不改状态、不发布、不影响检索（生效中仍是生效中；只有新建策略落「草稿」）；「保存并发布」＝参数立即对该策略的下次检索生效（直接执行、不弹二次确认）；「取消 / × / 遮罩 / Esc」＝关闭回列表，未保存的新建空行丢弃，列表不重绘、不丢。
· 基本信息：策略名称（必填，保存 / 发布前校验「请填写策略名称」）+ 版本 / 状态（只读回显，状态取值：草稿 / 生效中 / 已下线）。
· 向量参数：下拉只有一项产线白名单内的统一向量空间（置灰不可切换，旁注「统一检索固定一套向量空间，不可切换」），白名单外向量禁入检索库——白名单是假跨模态风险防线。
· 召回与融合：相似度阈值（默认 0.60）+ 四模态权重（文本 / 图像 / 视频 / 音频，合计须为 100%）；阈值口径见上方「召回与融合口径」，行内「权重合计 100% ✓ / （需调整至 100%）」是校验显示而非说明句，≠100% 时数字标红（.sum-line.over）且拦截保存 / 发布。
· 重排参数：一个开关「启用重排」，右侧实时标「开 / 关」。开＝在向量召回结果上用精细模型再排一次（更准、多几十毫秒）；关＝直接按向量召回的相似度顺序返回（更快、可能有少量错序）。
· 生效口径：各段参数在底部一次性写入——「保存草稿」只存不生效，「保存并发布」与运维弹窗「发布此草稿」是两处生效入口。
· 只读与状态：原型不提供角色切换，进入本页即可编辑（含系统预置行）；正式实现按登录态与库授权判定，未授权时整窗控件与「保存草稿 / 保存并发布」禁用。
· 演示口径：演示值只存在于字段默认值（新建时名称留空待填、阈值 0.60、权重 50/30/10/10、模型「图文对齐 · CLIP双塔 v3」），正式实现由接口回填。

总览页面定位 / 闭环 / 功能清单 / 编号与演示性质

本页定位【设计】

检索中心的「大脑」：三段式管理检索策略——①向量 ②召回与融合（相似度阈值 / 四模态权重）③重排，每段只留参数本身，加默认策略兜底；策略经评测（P8）验证后保存并发布，对 P1 下次检索即生效。页面类型＝配置/编辑页（规范2.3），编辑弹窗底部主操作唯一＝保存并发布。

平台全景闭环【研发】

P7 结果运营反馈 / P8 评测建议 → 本页配三段参数 → 保存并发布 → P1 下次检索生效 → P6 搜索行为（任务号 / 操作人 / 结果数 / 赞踩） → P2 结果 → 回到 P7 / P8；P4 新库投产由数据源库管理页自行校验，本页默认策略行直接编辑兜底参数。

功能清单【设计】

策略列表（含系统预置兜底行，每页 10 条分页）、新建 / 编辑策略弹窗（基本信息 + 向量 + 召回与融合 + 重排）、保存草稿 / 保存并发布、策略上线 / 下线（下线选原因 + 影响说明）、运维弹窗（变更评估 4 项 diff / 版本回滚，版本保留 10 个）、策略一致性检查（5 项）、权限与编号。

编号规范与演示性质【研发】

策略 ID 按《平台相关ID生成规范-1026》32.1：内部主键雪花 19 位不外暴；业务编号=STG+yyMMdd+6 位安全码（等宽可复制）；语义编码=小写下划线、发布不可改。版本号 v1/v2/v3 保留。
本页 库/任务/策略编号已按 canonical 统一为 KB / TASK / STG；评测、反馈为历史前缀，正式实现按 canonical 归并为 EVL / FBK。
所有校验结果均为页内写死演示，不请求真实引擎，不构成交付承诺。

处理规则
  • 点「编辑」或行任意处载入：弹出编辑弹窗并载入参数字段；系统默认策略为系统预置行（与其他策略一样可编辑；只读口径见「权限与编号」）

编辑新建 / 编辑策略弹窗（三段参数）含演示限制，正式实现需另定
职责
在弹窗内维护一条策略的基本信息与三段参数，底部「保存草稿 / 保存并发布」决定是否生效。
入口/前置

输入

异常与边界

状态

验收点

发布保存草稿 / 保存并发布（版本推进）
职责
把草稿参数落到生效版，并推进版本号、写入版本历史。
处理规则
  • 保存并发布：参数与上一生效版不同 → 版本号 +1；相同则沿用当前版本
  • 发布后：生效中 / 草稿行转「生效中」；已下线行只换参数与版本、仍为「已下线」（要回检索台需点「上线」）；更新时间刷新、写版本历史、清空待发布草稿

运维变更评估 / 版本回滚（运维弹窗）含演示限制，正式实现需另定
职责
改前看影响、改坏能回滚：对单条策略做配置 diff 与版本回滚。
入口/前置
策略行「运维」按钮；弹窗标题「策略运维 · 策略名」。
输入
  • 当前策略（列表行带入）
  • 对比策略下拉（默认系统默认策略）
  • 该策略版本历史
处理规则
  • 变更评估：展示向量参数 / 相似度阈值 / 融合权重 / 重排方案四项 diff，差异项蓝色标注
  • 有 OPS_PENDING 待发布登记时才出现「发布此草稿 / 放弃草稿」
  • 版本回滚：版本历史 6 列（版本 / 策略名称 / 变更摘要 / 发布时间 / 状态 / 操作）；未发布草稿单独列在顶部且不可回滚，当前版本按钮置灰，其余版本「回滚到此」→ 二次确认 → 回写版本 / 状态 / 配置 + 回滚核验条；每个版本记录发布时的策略名称与参数快照，版本历史只保留最近 10 个版本，超出后最早的自动清理，需要长期留档的版本请在外部登记
输出
  • 发布 / 回滚回执（版本 + 配置摘要 + 时间 + 回执号）
  • 列表行与版本历史同步更新
异常与边界
无草稿时点击发布 / 放弃→提示「当前无待发布草稿」；回滚当前版本→「无需回滚」；未知策略号不打开弹窗。
验收点
diff 四项与列表参数一致；默认对比系统默认策略；有 OPS_PENDING 时才有「发布此草稿 / 放弃草稿」；回滚后版本、状态、参数与历史一致。
