# 跨模态检索中心 · 接口调用示例

> 服务地址：`http://<host>:6300`。所有算子共用四协议，路径前缀为算子编号。
> 返回统一信封：`{"code": 0, "msg": "success", "data": {...}}`；业务失败 `code=1`，`msg` 带原因。
> 以下命令均为单行，可直接复制执行（`HOST` 按 127.0.0.1:6300 示例）。

## 〇、四协议速查

| 协议 | 方法与路径 | 说明 |
| --- | --- | --- |
| 健康检查 | GET `/{operatorId}/healthz` | 统一入口 GET `/healthz` 聚合全部算子 |
| 上传文件 | POST `/{operatorId}/uploadFile?uniqueId=xxx` | multipart 文件字段；zip 自动解压 |
| 执行算子 | POST `/{operatorId}/predict` | JSON 请求体，见各算子说明书 |
| 清理任务 | POST `/{operatorId}/removeFile?uniqueId=xxx` | 删除该任务的上传与输出目录，幂等 |

管线字段：`uniqueId`（任务号，字母数字下划线短横线）、`inputFile`（输入路径）、`lineageFile`（可选血缘回传）、`outputFile`（输出文件路径）。

路径约定：`inputFile`/`queryFile`/`indexDir`/`evalFile` 均推荐**项目根相对逻辑路径**（`runtime/...`、`dataset/...`，绝对路径兼容）；算子返回的 `sourceFile`/`locator.path`/`outputFile` 亦为逻辑路径（`outputFile` 为服务端绝对路径，仅用于下一环透传）。

## 一、建库链完整串行调用（批量，401→405；402/406 已不在平台编排内）

前提：样例数据集打包为 `dataset/sample.zip`（内含 notes.txt、dog_beach.jpg、podcast.wav、clip.mp4 与 metadata.json）。

### 1. 上传数据集（401 输入目录）

```
curl -X POST "http://127.0.0.1:6300/401m_ingest_check/uploadFile?uniqueId=build_001" -F "file=@dataset/sample.zip"
```

返回 `data.file`（落盘路径）与 `data.zipEntries`（zip 内条目数，非 zip 为 0）。上传内容统一落在约定目录 `runtime/{operatorId}/input/{uniqueId}`，后续 `inputFile` 直接使用该目录。

### 2. 数据接入校验（401）

```
curl -X POST "http://127.0.0.1:6300/401m_ingest_check/predict" -H "Content-Type: application/json" -d "{\"uniqueId\":\"build_001\",\"inputFile\":\"runtime/401m_ingest_check/input/build_001\"}"
```

输出：`data.report` 含 decodableRate、modalityCoverage、countRate；`data.outputFile` 为 report.json。

### 3. 数据集评定（402，平台建库链已不调用，仅保留算子能力）

```
curl -X POST "http://127.0.0.1:6300/402m_dataset_score/predict" -H "Content-Type: application/json" -d "{\"uniqueId\":\"build_001\",\"inputFile\":\"runtime/401m_ingest_check/output/build_001/report.json\"}"
```

输出：`data.score` 综合评分，`data.decision` 为 pass、suspend、reject 三档之一。pass 才继续建库。

### 4. 模态内容解析（403）

```
curl -X POST "http://127.0.0.1:6300/403m_modal_parse/predict" -H "Content-Type: application/json" -d "{\"uniqueId\":\"build_001\",\"inputFile\":\"runtime/401m_ingest_check/input/build_001\"}"
```

输出：`data.outputFile` 为 items.jsonl（检索单元清单），`data.counts` 分模态计数。

### 5. 多模态向量化（404，批量模式）

```
curl -X POST "http://127.0.0.1:6300/404m_embed/predict" -H "Content-Type: application/json" -d "{\"uniqueId\":\"build_001\",\"inputFile\":\"runtime/403m_modal_parse/output/build_001/items.jsonl\"}"
```

输出：`data.outputFile` 为 embeddings.jsonl，`data.dim` 为 512，`data.modelVersion` 记录向量模型版本。

### 6. 向量索引构建（405）

```
curl -X POST "http://127.0.0.1:6300/405m_index_build/predict" -H "Content-Type: application/json" -d "{\"uniqueId\":\"build_001\",\"inputFile\":\"runtime/404m_embed/output/build_001/embeddings.jsonl\",\"itemsFile\":\"runtime/403m_modal_parse/output/build_001/items.jsonl\",\"indexDir\":\"runtime/demo_index\"}"
```

输出：`data.indexDir` 索引目录，`data.total` 入库条目数。重复执行为幂等重建。

### 7. 投产召回率校验（406，平台建库链已不调用，仅保留算子能力）

```
curl -X POST "http://127.0.0.1:6300/406m_recall_check/predict" -H "Content-Type: application/json" -d "{\"uniqueId\":\"build_001\",\"indexDir\":\"runtime/demo_index\",\"evalFile\":\"dataset/sample/eval_queries.jsonl\"}"
```

输出：`data.recall` 命中率，`data.decision` 为 pass 或 fail，未达标不投产。

## 二、在线检索链路（常驻服务）

### 1. 查询理解（407，可选前置）

```
curl -X POST "http://127.0.0.1:6300/407m_query_understand/predict" -H "Content-Type: application/json" -d "{\"uniqueId\":\"q_001\",\"query\":\"苹果的照片\"}"
```

`data.needClarify=true` 时将 `data.clarifyOptions` 交前端展示，用户选定后以改写查询进入 408。

### 2. 检索服务（408 主接口）

文本检索：

```
curl -X POST "http://127.0.0.1:6300/408m_retrieval/search" -H "Content-Type: application/json" -d "{\"query\":\"一只狗在沙滩上奔跑\",\"indexDir\":\"runtime/demo_index\",\"topK\":10}"
```

带策略参数（权重合计必须 100，精排开启）：

```
curl -X POST "http://127.0.0.1:6300/408m_retrieval/search" -H "Content-Type: application/json" -d "{\"query\":\"租赁合同里关于宠物的条款\",\"indexDir\":\"runtime/demo_index\",\"weights\":{\"text\":40,\"image\":20,\"audio\":20,\"video\":20},\"rerank\":true}"
```

图片检索（queryFile 换成查询文件路径）：

```
curl -X POST "http://127.0.0.1:6300/408m_retrieval/search" -H "Content-Type: application/json" -d "{\"queryFile\":\"dataset/sample/dog_beach.jpg\",\"indexDir\":\"runtime/demo_index\"}"
```

输出：`data.resultSetId` 结果集编号（RST 前缀），`data.items` 按相似度降序，每条含 rank、score、modality、itemId、sourceFile、locator、text；`data.strategy` 为本次策略快照；`data.elapsedMs` 为服务端耗时。

### 3. 评测执行（409）

```
curl -X POST "http://127.0.0.1:6300/409m_evaluate/predict" -H "Content-Type: application/json" -d "{\"uniqueId\":\"eval_001\",\"indexDir\":\"runtime/demo_index\",\"evalFile\":\"dataset/sample/eval_queries.jsonl\"}"
```

输出：`data.metrics` 三指标（recall@10、precision@10、ndcg@10），`data.conclusion` 达标结论；同一索引第二次执行自动与上次对比（`data.comparison`）。

带评测对象策略参数（对比"草稿 vs 生效"时用）：

```
curl -X POST "http://127.0.0.1:6300/409m_evaluate/predict" -H "Content-Type: application/json" -d "{\"uniqueId\":\"eval_002\",\"indexDir\":\"runtime/demo_index\",\"evalFile\":\"dataset/sample/eval_queries.jsonl\",\"weights\":{\"text\":40,\"image\":20,\"audio\":20,\"video\":20},\"rerank\":true}"
```

### 4. 清理任务（任一算子）

```
curl -X POST "http://127.0.0.1:6300/403m_modal_parse/removeFile?uniqueId=build_001"
```
