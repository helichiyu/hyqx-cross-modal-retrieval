# 算子模型设计

## 投产召回率校验

### 投产召回率校验

#### 建库后抽检回放校验规则

##### 基础信息

| 项 | 值 |
| --- | --- |
| 算子编号 | 406m_recall_check |
| 算子名称 | 投产召回率校验 |
| 算子类型 | 批量处理 |
| 接口路径 | /406m_recall_check/predict |
| 输入 | indexDir 索引目录与 evalFile 抽检查询集 |
| 输出 | 校验结果 recall.json |
| 依赖模型 | 间接依赖多模态向量化算子完成查询向量化 |

##### 技术方案

索引构建完成后、投产之前，用抽检查询集对索引做回放校验。每条抽检查询先调用多模态向量化算子得到查询向量，再在 clip 通道执行检索，命中判定为结果中出现答案指定的 itemId 或来源文件。全部查询的命中率与阈值比较，给出 pass 或 fail 结论，未达标时阻止投产。默认命中阈值为 0.8，可在请求参数中覆盖。

##### 技术实现

1. 读取抽检查询集 evalFile，每行包含 query 与 answers 两个字段
2. 逐条调用多模态向量化算子将查询文本编码为向量
3. 在指定索引的 clip 通道检索前 topK 条结果
4. 按 itemId 或来源文件名判定命中
5. 汇总命中率，与阈值比较给出 pass 或 fail
6. 将逐条命中明细与结论写入 recall.json

##### 资源要求

| 资源 | 要求 |
| --- | --- |
| CPU | 2 核及以上 |
| GPU | 不需要 |
| 内存 | 2 GB 及以上 |
| 磁盘 | 输出报告小于 1 MB |

##### 模型性能指标

本算子不含训练模型。在样例索引与 3 条抽检查询上实测，单轮校验耗时约 1.6 秒，样例查询命中率 1.0。

##### 投产召回率校验-输入示例

```
POST /406m_recall_check/predict
{
  "uniqueId": "task_001",
  "indexDir": "runtime/demo_index",
  "evalFile": "dataset/sample/eval_queries.jsonl",
  "threshold": 0.8,
  "topK": 10
}
```

threshold 与 topK 可省略。evalFile 每行结构为 query 加 answers 数组。

##### 投产召回率校验-输出示例

```
{
  "code": 0,
  "msg": "success",
  "data": {
    "outputFile": "runtime/406m_recall_check/output/task_001/recall.json",
    "recall": 1.0,
    "threshold": 0.8,
    "decision": "pass",
    "queries": 3
  }
}
```
