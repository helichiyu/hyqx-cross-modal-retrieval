# 算子模型设计

## 数据集评定

### 数据集评定

#### 加权评分与三档判定规则

##### 基础信息

| 项 | 值 |
| --- | --- |
| 算子编号 | 402m_dataset_score |
| 算子名称 | 数据集评定 |
| 算子类型 | 批量处理 |
| 接口路径 | /402m_dataset_score/predict |
| 输入 | 数据接入校验算子产出的 report.json |
| 输出 | 评定结果 score.json |
| 依赖模型 | 无 |

##### 技术方案

对上游校验报告中的三项指标加权求和得到综合评分，按两条阈值线给出三档判定。默认权重为可解码率 0.5、模态覆盖率 0.3、数量一致率 0.2；默认通过线为 0.8，缓议线为 0.5。评分不低于通过线判为 pass，低于通过线但不低于缓议线判为 suspend，低于缓议线判为 reject。权重与阈值均可在请求参数中覆盖，覆盖时权重合计必须为 1。

##### 技术实现

1. 读取 report.json，提取可解码率、模态覆盖率、数量一致率
2. 合并默认权重与请求覆盖权重，校验权重合计为 1
3. 按权重加权求和得到综合评分
4. 对照通过线与缓议线给出 pass、suspend、reject 三档判定
5. 将评分、权重、阈值与判定结论写入 score.json

##### 资源要求

| 资源 | 要求 |
| --- | --- |
| CPU | 1 核及以上 |
| GPU | 不需要 |
| 内存 | 512 MB 及以上 |
| 磁盘 | 输出报告小于 1 MB |

##### 模型性能指标

本算子不含训练模型。在样例校验报告上实测，单次评定耗时约 0.3 秒，三档判定分支均经端到端测试验证。

##### 数据集评定-输入示例

```
POST /402m_dataset_score/predict
{
  "uniqueId": "task_001",
  "inputFile": "runtime/401m_ingest_check/output/task_001/report.json",
  "weights": {"decodableRate": 0.5, "modalityCoverage": 0.3, "countRate": 0.2},
  "passLine": 0.8,
  "suspendLine": 0.5
}
```

weights、passLine、suspendLine 均可省略，省略时使用默认值。

##### 数据集评定-输出示例

```
{
  "code": 0,
  "msg": "success",
  "data": {
    "outputFile": "runtime/402m_dataset_score/output/task_001/score.json",
    "score": 1.0,
    "decision": "pass",
    "weights": {"decodableRate": 0.5, "modalityCoverage": 0.3, "countRate": 0.2},
    "passLine": 0.8,
    "suspendLine": 0.5
  }
}
```
