# 算子模型设计

## 评测执行

### 评测执行

#### Recall Precision nDCG 三指标评测规则

##### 基础信息

| 项 | 值 |
| --- | --- |
| 算子编号 | 409m_evaluate |
| 算子名称 | 评测执行 |
| 算子类型 | 批量处理 |
| 接口路径 | /409m_evaluate/predict |
| 输入 | indexDir 索引目录与 evalFile 评测集 |
| 输出 | 评测报告 eval_report.json、历史记录 history.jsonl |
| 依赖模型 | 间接依赖检索服务算子执行检索 |

##### 技术方案

对评测集逐条调用检索服务执行检索，按三项指标计算质量分。召回率按被覆盖的答案数计，同一答案的多个条目只计一次；精确率按命中条目数除以截取条数；nDCG 按命中位置的折损累加并做理想归一。三项指标与验收线比较，全部达标结论为 pass，否则为 fail 并列出未达标指标。每次评测结果追加写入历史文件，同一索引的下一次评测自动与上次结果对比，给出各指标差值与是否提升，供策略调参对比使用。

##### 技术实现

1. 读取评测集 evalFile，每行包含 query 与 answers 两个字段
2. 逐条调用检索服务获取前 K 条结果
3. 同一答案只计首次命中，计算该条查询的召回率、精确率、nDCG
4. 全评测集取平均得到三项综合指标
5. 对照验收线得出结论与未达标指标清单
6. 追加历史记录，与同索引上次评测结果对比生成差值
7. 将指标、明细、对比写入 eval_report.json

##### 资源要求

| 资源 | 要求 |
| --- | --- |
| CPU | 2 核及以上 |
| GPU | 不需要 |
| 内存 | 2 GB 及以上 |
| 磁盘 | 输出报告小于 1 MB |

##### 模型性能指标

本算子不含训练模型。在样例索引与 3 条评测查询上实测，单轮评测耗时约 3.8 秒。样例评测集三项指标：recall@10 为 1.0，precision@10 为 0.1333，nDCG@10 为 1.0。

##### 评测执行-输入示例

```
POST /409m_evaluate/predict
{
  "uniqueId": "task_001",
  "indexDir": "runtime/demo_index",
  "evalFile": "dataset/sample/eval_queries.jsonl",
  "k": 10,
  "lines": {"recall": 0.8},
  "weights": {"text": 40, "image": 20, "audio": 20, "video": 20},
  "rerank": false
}
```

k 与 lines 可省略。lines 中置空的指标不卡线。evalFile 每行结构为 query 加 answers 数组，answers 元素为 itemId 或来源文件名。weights 与 rerank 为**评测对象策略参数**，可省略（省略时按服务端当前默认策略执行）；传入时评测全程按该策略检索，用于对比生效策略与候选草稿策略。

##### 评测执行-输出示例

```
{
  "code": 0,
  "msg": "success",
  "data": {
    "outputFile": "runtime/409m_evaluate/output/task_001/eval_report.json",
    "metrics": {"recall@10": 1.0, "precision@10": 0.1333, "ndcg@10": 1.0},
    "conclusion": "pass",
    "failedLines": [],
    "comparison": {"recall@10Delta": 0.0, "precision@10Delta": 0.0,
                    "ndcg@10Delta": 0.0, "improved": true}
  }
}
```

comparison 在同索引首次评测时为 null。
